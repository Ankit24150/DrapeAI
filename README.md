## What’s inside

- **Fashion editorial landing page** introducing the DrapeAI concept and its try-on experience.
- **Login and sign-up screens** with a front-end demo flow.
- **Logged-in fitting-room page** with a personalized welcome and visual garment preview.
- **Responsive styling** built with Tailwind CSS and custom CSS.
- **Subtle interface motion** and scroll reveals for a polished browsing experience.

## Project status

This repository currently contains the front-end experience and a visual fitting-room concept. **AI garment-on-person generation, image upload processing, product catalog data, and persistent accounts are not connected yet.** The current login flow is a UI demo and does not authenticate against a production account service.

The project’s longer-term goal is to let shoppers preview garments on their own photos, helping them make more confident choices and reducing avoidable returns.

## Getting started

### Requirements

- Node.js 18 or newer
- npm

### Install and run

```bash
git clone https://github.com/Ankit24150/DrapeAI.git
cd DrapeAI
npm install
npm run dev
```

Open the local URL printed by Vite to explore the app.

### Production build

```bash
npm run build
npm run preview
```
