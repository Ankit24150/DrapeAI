# DrapeAI

> See the drape before the delivery.

## What is DrapeAI?

DrapeAI is an AI-powered virtual try-on platform for fashion. It helps users preview how garments may look on their own body before buying them.

Users can create an account, sign in securely, and explore a personalized fitting-room experience designed around their style and wardrobe.

## Why is it used?

Online shopping often makes it difficult to understand how a garment will look, fit, or fall on a real person. DrapeAI helps users:

- Preview outfits before purchasing
- Understand fit, style, and fabric drape
- Reduce uncertainty while shopping online
- Explore more looks with confidence
- Save time and make better fashion decisions

## Technologies Used

- **React** - Builds the user interface and reusable components
- **TypeScript** - Adds type safety and maintainable code
- **Vite** - Provides fast development and production builds
- **Tailwind CSS** - Handles responsive styling and design utilities
- **Custom CSS** - Powers animations, visual effects, and the fitting-room visuals
- **React Router** - Manages landing, login, signup, and hero page routes
- **Lucide React** - Provides interface icons
- **Supabase Auth** - Handles email/password authentication and Google OAuth
- **Supabase Edge Functions** - Runs secure server-side functionality
- **Resend** - Sends DrapeAI welcome emails to users

## Main Pages

- `/` - DrapeAI landing page
